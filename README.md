# Frutiger Dreams — E-commerce Estético

Frutiger Dreams es un sitio web inspirado en la estética **Frutiger Aero**, un estilo visual característico de los años 2000 que combina tecnología, optimismo, colores suaves y transparencias.  
El proyecto consiste en un **e-commerce interactivo**, desarrollado como trabajo final del curso, que permite visualizar productos, agregarlos a un carrito de compras y mantener su estado mediante almacenamiento local.

---

## Características principales

- Diseño visual inspirado en Frutiger Aero (blancos, grises, verdes y azules)
- Diseño responsivo utilizando **Flexbox**, **Grid** y **Media Queries**
- Visualización dinámica de productos obtenidos desde una **API REST**
- Carrito de compras funcional con:
  - Agregado y eliminación de productos
  - Modificación de cantidades
  - Cálculo dinámico del total
  - Persistencia de datos con **localStorage**
- Interactividad completa con **JavaScript**
- Formulario de contacto funcional mediante **Formspree**
- Buenas prácticas de accesibilidad y SEO básico

---

## Tecnologías utilizadas

- **HTML5** — Estructura semántica
- **CSS3** — Estilos personalizados + Flexbox + Grid
- **JavaScript (ES6)** — Lógica, DOM, fetch, eventos
- **API REST** — Obtención dinámica de productos
- **LocalStorage** — Persistencia del carrito
- **Formspree** — Envío del formulario de contacto
- **Git & GitHub** — Control de versiones y hosting

## Funcionalidades implementadas

### Productos
- Renderizado dinámico desde una API
- Tarjetas con imagen, nombre y precio
- Botón “Agregar al carrito” con feedback visual

### Carrito de compras
- Contador dinámico de productos
- Vista detallada del carrito
- Edición de cantidades
- Eliminación de productos
- Total actualizado en tiempo real
- Persistencia incluso al recargar la página

### Formulario de contacto
- Campos validados (nombre, correo y mensaje)
- Envío funcional a través de Formspree
